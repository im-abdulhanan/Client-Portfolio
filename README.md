# Creative Artsy Scrapbook Portfolio

A playful, interactive, scrapbook-style portfolio website inspired by [portfoliofy.io/preview/creative-artsy](https://portfoliofy.io/preview/creative-artsy).

## ✨ Features

- **Distinctive Hero Section**: Handjet pixel typography, hand-drawn outline container, tilted washi tape stickers, Post-it notes with doodle arrows, and floating photo avatars with wobble animations.
- **Sticky Folder Card Stack**: Signature file-folder project deck with chamfered tabs at progressive horizontal offsets (`0%`, `18%`, `36%`, `54%`) for smooth stacked scrolling.
- **Interactive Case Study Modals**: In-depth project view with challenge, solution, impact metrics, and deliverables badges.
- **Bespoke Vector Mockups**: Custom responsive vector illustrations for transit routing, fintech expense splitting, developer onboarding terminal, and smart energy home dashboards.
- **Interactive Scrapbook Playground**: Live sticker stamp canvas allowing visitors to pin playful badges onto a ruled notebook canvas.
- **Festive Contact Card**: Giant tilted yellow card with confetti particle explosion and one-click email copying.
- **Authentic Paper Aesthetics**: Ruled notebook paper texture with 34px pitch lines and subtle paper grain overlay.
- **Full Responsive Design**: Sticky navigation header with active section tracking pills and mobile drawer.

## 🛠️ Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **GSAP & ScrollTrigger**
- **Lucide React**
- **Canvas Confetti**

## 🚀 Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally (Dev Server)
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
